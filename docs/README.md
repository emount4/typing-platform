# contracts/

Общая зона Матвея и Егора. Не принадлежит ни одному сервису.

Правило одно: **изменение в этом каталоге ломает чужой код.** Поэтому pull request,
трогающий `contracts/`, обязателен к ревью вторым участником — даже если это правка
одного поля.

## Состав

| Файл | Что фиксирует | Кто основной автор |
|---|---|---|
| `openapi.yaml` | REST наружу: клиент → Python, `/api/*` | Матвей |
| `websocket.md` | Кадры между клиентом и Go, `/ws` | оба |
| `internal.md` | Go → Python (`/internal/*`) и общие ключи Redis | оба |
| `jwt.md` | Claim'ы токена: Python выпускает, Go проверяет | оба |
| `generator.md` | Python → Go-генератор (этап 6) | Егор |
| `examples/` | Эталонные JSON для тестов обеих сторон | оба |

## Как читать статусы

В каждом документе у раздела стоит метка:

- ✅ **зафиксировано** — реализовано или реализуется прямо сейчас, менять только через PR с ревью;
- 🟡 **согласовано, не реализовано** — форма полей утверждена, писать код можно;
- ⚪ **эскиз** — набросок на будущий этап, поля почти наверняка изменятся. Не закладываться.

Эскизы существуют не для того, чтобы их реализовывать заранее, а чтобы сегодняшние решения
не сделали их невозможными. Если новый эскиз требует переделки ✅-раздела — это повод
обсудить сейчас, а не на этапе 4.

## Как пользоваться `examples/`

Это главный механизм защиты от расхождения (см. раздел 4.8 документации).

- **Go** в своих тестах проверяет, что сериализует **ровно такой** запрос:
  `internal_runs.request.json` сравнивается с тем, что уходит в `SubmitRun`.
- **Python** в pytest проверяет, что **принимает ровно такой** JSON и что его ответ
  совпадает с `internal_runs.response.json`.
- **Фронтенд** в Vitest гоняет `ws_solo_session.jsonl` через мок-сокет.

Смысл: если кто-то поменял поле в одиночку, красный тест появляется у второго **до влития
в main**, а не через неделю на боевом сервере. Поэтому пример правится **в том же PR**, что и
сам контракт, и никогда отдельно.

Сравнение — строгое по набору полей (не «есть ли нужные», а «нет ли лишних»): молча
добавленное поле — такое же расхождение, как молча удалённое.

## Версии

- **REST** версионируется путём: `/api/v1/...`. Ломающее изменение → `/api/v2/...`,
  старая версия живёт до переезда фронтенда.
- **WebSocket** версионируется полем `v` в кадре `auth`. Go отвечает `error` с кодом
  `protocol_version_unsupported`, если не умеет запрошенную версию.
- **`/internal/*`** не версионируется: обе стороны едут одним монорепозиторием и одним
  деплоем. Ломать можно, но только одним PR, меняющим обе стороны сразу.

Совместимое изменение (можно без нового номера версии): **добавление** необязательного поля,
добавление нового типа сообщения, добавление значения в enum, у которого явно описано
поведение по умолчанию для неизвестных значений.

Ломающее (нужен новый номер): удаление или переименование поля, смена типа, смена смысла
единиц измерения, превращение необязательного поля в обязательное.

## Процесс изменения контракта

1. PR с правкой `contracts/` + пример в `examples/` в том же коммите.
2. В описании PR — одна строка: **что ломается у второго**. Если ничего — так и написать.
3. Ревью второго участника обязательно. Здесь молчаливый approve вреднее, чем где-либо ещё.
4. Реализация — отдельным PR, уже без обсуждения формы.

## Расхождения с черновиком от 13.08 (утро)

По проекту уже был комплект контрактов. Часть файлов при сборке этой версии оказалась
перезаписана; уцелевшие лежат в `_prev_session/`. Ниже — где две версии разошлись.

**Приведено к раннему черновику** (он был первым, менять без причины незачем):
`keystroke.batch` использует `items` и `seq`; `session.started` отдаёт `allow_backspace`;
`session.finish` и `session.progress` несут `t`; JWT живёт отдельным файлом `jwt.md`.

**Осталось разойтись — нужно выбрать одно:**

| Что | Ранний черновик | Эта версия | Комментарий |
|---|---|---|---|
| Агрегаты по клавишам | считает Go, шлёт `key_stats[]` | считает Python из сырых `keystrokes[]` | Открытый вопрос №2. Развилка настоящая, см. `internal.md` §3.2 |
| Ключ идемпотентности | `client_run_id` (генерит клиент) | `session_id` (генерит Go) | Клиентскому идентификатору нельзя доверять: подменённый клиент пришлёт один и тот же и затрёт чужой забег |
| Тип `run_id` | `int` (1284) | UUID-строка | Числовой раскрывает число забегов в системе и удобен для перебора |
| Сохранение результата | один кадр `session.result` с `saved: true` | `session.result` сразу + `session.saved` после ответа Python | Раздел 4.7: при недоступности Python первый вариант заставляет ждать или врать |
| Кадр ошибки | `session.error` с вложенным `error` | `error` с плоскими полями и `fatal` | `fatal` нужен клиенту, чтобы понять, рвать ли соединение |
| Счётчики | `chars_typed` + `errors` | `typed` + `correct` + `errors` | С Backspace `chars_typed` неоднозначен: входит ли в него стирание |
| Метрики в `session.progress` | сервер шлёт `wpm` и `accuracy` | не шлёт, считает клиент | Две цифры WPM в полёте — гарантированный источник расхождений на экране |

Каждая строка — решение на пять минут, но принятое молча оно всплывёт через месяц.
