# contracts/examples/

Эталонные JSON. Не документация — **тестовые фикстуры**, которые обе стороны гоняют в CI.

Механизм из раздела 4.8 документации: Go проверяет, что генерирует ровно такой запрос,
Python — что принимает ровно такой. Кто-то поменял поле в одиночку → красный тест у второго
**до влития в main**, а не через неделю на проде.

## Формат `ws_solo_session.jsonl`

Одна строка — один кадр, в порядке отправки:

```json
{"dir": "c2s", "frame": { "type": "session.start", ... }}
```

`dir`: `c2s` — клиент → сервер, `s2c` — сервер → клиент. Это обёртка фикстуры;
**в реальном соединении её нет**, по проводу идёт содержимое `frame`.

## Что в этой сессии

Текст `«Осень пришла рано.»` — 18 графем. Пользователь на пятом символе ошибается
(набирает `б` вместо `ь`), стирает Backspace и исправляется. Специально короткий забег:
его можно проверить руками.

| Величина | Значение |
|---|---|
| нажатий всего | 20 |
| из них Backspace | 1 |
| `typed` (знаменатель точности) | 19 |
| `correct` | 18 |
| `errors` | 1 |
| `duration_ms` | 2380 |
| `accuracy` | 94.74 |
| `wpm_raw` | 95.80 |
| `wpm_net` | 90.76 |

Проверка формул из `websocket.md` §3.4:

```
accuracy = 18 / 19 * 100                 = 94.74
duration = 2380 − 0                      = 2380 мс  (последнее нажатие минус первое)
minutes  = 2380 / 60000                  = 0.039667
wpm_raw  = (19 / 5) / 0.039667           = 95.80
wpm_net  = (18 / 5) / 0.039667           = 90.76
```

Обратите внимание на три вещи, которые фикстура проверяет специально:

1. **`typed` = 19, а не 20** — Backspace не входит в знаменатель точности.
2. **`duration_ms` от первого нажатия**, а не от `session.started`. Если считать от старта
   сессии, число будет другим, и тест покраснеет — ради этого он и написан.
3. **Батчей 16, а не один.** При 150-миллисекундном троттлинге в батч попадает
   один-два символа. Это ожидаемо, см. `websocket.md` §3.3.

Округление — до **двух знаков после запятой**, `round half to even` (это дефолт и в Python,
и в Go при форматировании `%.2f`). На третьем знаке языки разъезжаются, поэтому сравнивать
float'ы в тестах надо с допуском `1e-2`, а не на точное равенство.

## Правила

- Пример правится **в том же PR**, что и сам контракт. Никогда отдельно.
- Сравнение строгое **по набору полей**: молча добавленное поле — такое же расхождение,
  как молча удалённое.
- Числа в примерах должны сходиться между собой. `internal_runs.request.json` и
  `session.result` в `ws_solo_session.jsonl` описывают **один и тот же забег** — если
  правите один, пересчитайте второй.
