# Контракт генератора упражнений ⚪

Канал: **Python API → Go-генератор**, HTTP внутри docker-сети. База `http://generator:8090`.
Наружу не выставляется.

Этап 6. **Эскиз.** Фиксировать отдельным PR перед началом этапа.

Единственное место, где Python звонит в Go. Исключение из правила 4.1 допустимо потому,
что генератор — **чистая функция**: не ходит в базу, не держит состояния, не знает про
сессии и комнаты. С realtime-сервисом не связан вообще и деплоится отдельно.

---

## `POST /generate`

```json
{
  "lang": "ru",
  "alphabet": ["ф","ы","в","а","о","л","д","ж"],
  "length": 180,
  "target_bigrams": ["ыв", "лд"],
  "seed": 1755110531
}
```

| Поле | Тип | Обяз. | Описание |
|---|---|---|---|
| `lang` | enum | да | `ru` \| `en`. Определяет таблицу частотностей |
| `alphabet` | string[] | да | **Жёсткое ограничение.** Ни одного символа вне списка |
| `length` | int | да | Целевая длина в графемах, ±10% |
| `target_bigrams` | string[] | нет | Связки, частоту которых надо поднять |
| `seed` | int | нет | Для детерминизма. Без него — случайно |

**Ответ `200`:**

```json
{
  "content": "фыва олдж авыф жалд ...",
  "length": 178,
  "alphabet_used": ["ф","ы","в","а","о","л","д","ж"," "],
  "bigram_frequencies": { "ыв": 0.041, "лд": 0.038 }
}
```

`bigram_frequencies` — фактическая доля целевых связок в выдаче. Нужна не приложению,
а тесту: «заданные связки встречаются заметно чаще своей базовой частоты» проверяется
по этому полю, а не пересчётом текста на стороне Python.

**Ошибки:** `422` — пустой алфавит, `length` вне диапазона, `target_bigrams` содержат
символы вне `alphabet` (это не «просто игнорируем» — это ошибка вызывающего).

---

## Инварианты

Обязательства генератора. Каждое проверяется тестом, каждое ломает продукт при нарушении.

1. **Ни одного символа вне `alphabet`.** Пробел разрешён всегда и в `alphabet`
   не перечисляется. Показать символ, которому ещё не учили, — это провалить весь смысл
   учебного режима.
2. **Детерминизм при фиксированном `seed`.** Иначе тест на частотность нечем стабилизировать.
3. **Фильтр нежелательных сочетаний.** Марковская цепь по слогам рано или поздно выдаёт
   неприличное слово. Предусмотреть сразу дешевле, чем ловить в проде на скриншоте
   от пользователя.
4. **Без обращений к базе и сети.** Таблицы биграмм — в образе, в `data/`.
5. **Пустой ответ невозможен.** Если сгенерировать не удалось — `500`, а не `content: ""`.
   Python на пустую строку не рассчитывает.

## Кто владеет структурой курса

Список уроков, алфавит каждого и критерий перехода лежат **у Python**, в конфигурационном
файле, а не в коде и не в генераторе. Методику придётся править по живым пользователям,
и пересборка сервиса ради смены порога с 97% на 95% — лишний шаг.

Генератор про уроки не знает вовсе. Он получает алфавит и длину.
